# SWYNEX Internship – Task 2: Data Cleaning and Basic Analysis

## Project Overview

This repository contains my work for Task 2 of the SWYNEX Technologies internship.

The task focuses on cleaning and performing basic quality assessment and statistical analysis of the GSE282302 dataset obtained from the NCBI Gene Expression Omnibus (GEO).

## Dataset Information

- **Dataset:** GSE282302
- **Source:** NCBI Gene Expression Omnibus (GEO)
- **Research area:** Pancreatic ductal adenocarcinoma (PDAC)
- **Analysis scope:** Sample-level metadata cleaning and quality assessment

## Tools and Technologies

- Python
- Google Colab
- Pandas
- Matplotlib
- GEOparse

## Work Performed

1. Retrieved and organised GEO sample metadata.
2. Cleaned whitespace and handled blank values.
3. Checked for duplicate records.
4. Summarised missing values.
5. Generated basic statistical summaries.
6. Visualised missing data.
7. Exported cleaned metadata and quality-control outputs.

## Repository Contents

- `SWYNEX_Task2_GSE282302_Data_Cleaning_Analysis.ipynb` – executed Python notebook.
- `outputs/` – generated CSV, PNG and JSON analysis outputs.

## Scope and Limitations

This task focuses on GEO sample metadata rather than the full gene-expression matrix. The analysis represents an initial data-cleaning and quality-assessment step, not a biological discovery or clinical prediction model.
